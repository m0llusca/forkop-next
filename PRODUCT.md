# Forkop Next

OpenWrt traffic manager preserving existing Forkop rules, DNS behavior, proxy
credentials and device exceptions during migration. Runtime dependencies and
supported package formats are declared in package metadata and build tooling.

Operators should understand whether routing works, why a destination uses a
connection, and how to undo a change. Everyday actions work on phone and desktop;
detailed diagnostics remain available in the advanced view.

The interface uses local assets, explicit live states, light/dark themes and
native LuCI integration. Never publish deployment credentials or private endpoint
metadata, and never invent live metrics. See docs/ACCEPTANCE.md for test limits.
