## Direction contract

THESIS: Forkop is a connection workspace. The home page answers whether access was checked, which outgoing server is selected and what needs attention before presenting detailed configuration.

OWN-WORLD: Existing slate/mint token palette, local system type, open section divisions, restrained 1px separators, readable tabular measurements and explicit native controls. Light and dark suit a router used on a phone or computer in varying ambient light; default inherits LuCI, then OS preference.

STORY: Open home, distinguish service/process from tested access, inspect selected outgoing connection, check deliberately, then manage servers or routing in the relevant section. Persistent labeled navigation keeps all six areas findable. Advanced features remain under their actual purpose.

FIRST VIEWPORT: Narrow internal sidebar beside a flexible work area. Common title/status/theme strip above it. Home has connection state and its primary check action on the left, selected outgoing server and change action on the right. A compact horizontal traffic definition list follows, then extra device routes and help only where needed. On mobile labeled navigation flows horizontally and content becomes one column.

FORM: User explicitly combines connection-first (own candidate 5) and workspace sections (candidate 4), surface seed 6ff26704. Code-first wireframes were shown; no comp round. Signature interaction is navigation preserving native draft fields and controller state while primary/secondary navigation stays synchronized with native LuCI tabs.
