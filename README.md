# Forkop Next

Персональный форк [Forkop](https://github.com/ushan0v/forkop) для OpenWrt.
Версия исходников **1.1.3** — кандидат для проверки перед установкой на роутер.
Сохраняются конфигурация `/etc/config/forkop`, служба и страницы LuCI.

## Возможности

- Новый обзор состояния: простой и подробный режимы, светлая и тёмная темы,
  адаптация для телефона, восстановление соединения с панелью.
- Профили с предварительным просмотром, импортом и экспортом; проверка перед
  применением, откат к рабочей конфигурации при ошибке и восстановление после прерывания.
- Выбор подключения для устройства, игровые наборы доменов магазинов и загрузок,
  временные правила с автоматическим удалением по сроку.
- Объяснение маршрута отдельно от явной проверки доступности через выбранное
  подключение. Неизвестное содержимое удалённых списков отмечается явно.
- Сохранение ручного выбора сервера; параллельное измерение задержек до четырёх
  запросов с ограничением времени и отметкой свежести.
- Smart Detect: ручное сравнение и включаемый пользователем фоновый поиск
  кандидатов по ошибкам. Повторные ошибки текущего маршрута и успешная проверка
  альтернативы создают предложение; правило применяется после принятия пользователем.
- Проверка обновлений 3x-ui и Xray из официальных репозиториев, проверка параметров
  выбранного подключения и явная HTTPS-проверка. Автоматической установки нет.
- Адаптация генерируемой конфигурации к схемам sing-box 1.13 и 1.14, исправления
  DNS, URLTest, фильтров и поведения переключения соединений.

Все прежние подробные вкладки Forkop сохранены. Новое назначение устройства
принимает IPv4; имеющиеся настройки IPv6 не отключаются. Игровые наборы охватывают
магазины и загрузки, а не весь игровой трафик. Профили сохраняются на роутере:
для хранения вне устройства нужен явный экспорт, содержащий секреты конфигурации.

## Совместимость с новыми ядрами

Версия Xray сама по себе не подтверждает совместимость. Транспорт, flow,
шифрование, TLS/REALITY и параметры обеих сторон должны совпадать и поддерживаться
установленным sing-box. Новые возможности Xray могут потребовать обновления
клиента или отдельного адаптера. Неподдерживаемые или непроверенные сочетания
показываются явно. Подробности: [совместимость](docs/COMPATIBILITY.md).

## Проверка и сборка

Разработка ведётся через TDD; исходные падения и последующие проверки записаны
в [docs/tdd](docs/tdd). Backend проверяется настоящим ucode с модулями fs/UCI,
а схемы — опубликованными ядрами sing-box 1.13.7 и 1.14.3 с фиксированными SHA256.

```sh
python3 tools/provision-test-cores.py
bash tests/run-backend.sh
cd fe-app-forkop
pnpm install --frozen-lockfile
pnpm lint
pnpm test --run
pnpm build
```

Для сборки нужен Linux с пользовательскими пространствами имён, fakeroot,
компилятором и инструментами из `build.sh`:

```sh
bash build.sh 1.1.3
```

Создаются IPK и APK; SDK проверяются по SHA256, инструмент переводов собирается
из закреплённого коммита LuCI. Запросы изменений запускают проверки и сборку без
публикации релиза. Установщик и обновления используют `m0llusca/forkop-next`.

## Установка и перенос

Перед установкой кандидата нужны резервная копия конфигурации и пакеты предыдущей
рабочей версии. Используйте проверенные пакеты релиза в формате вашей OpenWrt.
Старое руководство относится к исходному проекту и его установщику.

Приёмка на настоящем роутере описана в [контрольном списке](docs/ACCEPTANCE.md).
Лабораторные проверки не заменяют проверку DNS, IPv4/IPv6 и восстановления на устройстве.
