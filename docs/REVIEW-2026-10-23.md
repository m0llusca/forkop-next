# Повторная проверка Forkop Next — 23 октября 2026

Проверена версия 1.1.0 (`a1439fc9329ca2d468bf49fe9a94c6a2af498e53`).
Исправления подготовлены как кандидат 1.1.1. Основные направления проверяли
отдельные специалисты: транзакции и профили, маршрутизация, доступ к управлению,
интерфейс и независимая проверка объединённых изменений.

## Исправленные ошибки

- Повторное назначение устройства в прямой маршрут больше не удаляет предыдущие
  устройства из этого правила.
- Предпросмотр профиля привязан и к текущему конфигу, и к точному содержимому
  сохранённого профиля. Обновление списка, замена профиля и смена выбора сбрасывают
  подтверждение; внешняя правка текущего файла корректно обнаруживается.
- После перезапуска службы старый тег сервера не перезаписывает безопасный выбор
  по идентичности сервера. Снимок текущего выбора восстанавливается только при
  неизменном сгенерированном конфиге.
- Правила sniff и блокировки QUIC охватывают также IPv6 TPROXY.
- Объяснение маршрута учитывает истечение служебных правил и сохраняет
  неопределённость, когда неизвестно содержимое внешнего набора правил.
- Smart Detect распознаёт реальные ERROR-записи свежего sing-box при обычном
  уровне журналирования WARN и не принимает успешный INFO-трафик за ошибку.
- Управляющий API по умолчанию доступен только на loopback. Для LAN/WAN нужны
  явное включение YACD и секрет; сохранённый секрет действует и при отключённом
  YACD. Поле секрета доступно для LAN, скрывает значение и проверяет ввод.
- Роль LuCI «только чтение» больше не может запускать CLI/init-команды, способные
  менять состояние. Динамические страницы через прежний CLI требуют права записи;
  отдельный диспетчер для чтения в эту версию не добавлен.
- Обе панели используют авторизованные запросы LuCI при закрытом контроллере
  или HTTPS. Устаревшие ответы отбрасываются, запросы не накладываются, показатели
  восстанавливаются после перезапуска. Спецсимволы в WebSocket-токенах кодируются.

## Подтверждения и границы

В [журнале TDD](tdd/re-audit.md) зафиксированы исходные падения, исправления и
повторные проверки. Интерфейс: 583 теста в 54 файлах, форматирование, линтер,
проверка типов, сборка и исполнение итогового модуля LuCI прошли.

Полный лабораторный backend-прогон `cff38e6527d6` завершился с кодом 0:
70 shell-сценариев и 148 Python-тестов (82,144 с, без пропусков). Он включает
проверку схем опубликованными sing-box 1.13.7 и 1.14.3. Все ucode-модули
скомпилированы в обычном и строгом режимах (`f677e7f12184`, код 0).
Логи сохранены в `forkop-next-1.1.1-backend-verification.tar.gz`.

Отдельный стандартный анализ безопасности исходной версии выявил две проблемы
средней серьёзности: read ACL и открытый управляющий API. Их исправления описаны
выше и проверены регрессионными тестами. Канонический отчёт относится к исходному
коммиту; он не переписан после исправлений. Полный разбор безопасности охватил
20 из 436 файлов плюс выборочные фрагменты остальных путей: это частичное покрытие,
а не доказательство отсутствия других уязвимостей.

Проверки выполнялись в изолированной лаборатории. ACL проверен по семантике
настоящего JSON, без полноценного сеанса rpcd на OpenWrt. Роутер и VPS не менялись.
Совместимость будущих Xray/sing-box нельзя подтвердить только номером версии;
нужна проверка возможностей и реального соединения из
[контрольного списка приёмки](ACCEPTANCE.md).
