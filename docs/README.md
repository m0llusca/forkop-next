# Документация Forkop Next

Версия **1.2.0** сохраняет конфигурацию `/etc/config/forkop`, службу `forkop`,
команду `forkop` и подробные страницы LuCI. Пакеты и их SHA256 публикуются после
проверок исходного дерева и сборки; приёмка устройства выполняется отдельно.

[Старое руководство](UPSTREAM-README.md) сохранено как справочник исходного
Forkop. Его установочные команды и обещания не заменяют инструкции этого форка.
Актуальные границы проверки 1.2.0 находятся в описании выпуска и матрице.
Успех фикстур не заменяет проверку на конкретном устройстве.
