# Документация Forkop Next

службу `forkop`, команду `forkop` и подробные страницы LuCI. Установочные пакеты
1.1.5 ещё не опубликованы; последний опубликованный выпуск — 1.1.4.

[Старое руководство](UPSTREAM-README.md) сохранено как справочник исходного
Forkop. Его установочные команды и обещания не заменяют инструкции этого форка.
Актуальные границы проверки 1.1.5 находятся в описании подготовленного выпуска.
Успешные короткие серии соединений не заменяют длительную проверку на устройстве.
