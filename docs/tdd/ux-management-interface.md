# Unified Management UI/UX — Behavioral TDD & Multi-Angle Verification

Date: 2026-11-17
Scope: Task-oriented management interface unifying Tier-2 capabilities across `fe-app-forkop` and `luci-app-forkop` (`forkop` service, filesystem, UCI, and LuCI namespaces preserved).

## 1. UX Architecture & Design Principles Applied

Following function-driven UI/UX discipline (`web-app-development` — *"less, but better"*, progressive disclosure, zero decorative fluff, strict theme-token isolation, `>= 42px`/`44px` touch ergonomics, WCAG AA contrast in both Light and Dark themes):

1. **Task-Oriented Home Quick Scenarios (`fe-app-forkop/src/forkop/next/render.ts`)**
   - Added `Быстрые сценарии` (`section.fkp-next-panel.fkp-next-scenarios`) with 4 accessible `<button type="button" class="fkp-scenario-card" data-scenario="...">` cards covering the 4 highest-frequency user intents:
     - `vpn-warp`: opens the primary rule modal directly at `_wg_warp_helper` (or creates a rule if none exists) for `.conf` WireGuard / AmneziaWG import or 1-click Cloudflare WARP.
     - `gaming-nat`: jumps directly to the Devices / Gaming Console workflow (`[data-workspace-section="devices"]` + gaming `select`) without marking UCI drafts dirty.
     - `tspu-check`: jumps to Diagnostics, focuses `[data-tspu-domain]`, and pre-fills `youtube.com` if empty.
     - `torrents-direct`: jumps to Settings (`Основные`) and focuses `#cbid.forkop.settings.bittorrent_direct`.
   - Preserves all overview invariants: `0` backend RPC calls on initial mount, `panel.querySelector('select') === null` in workspace mode, and first `<input>` remains `connection_domain`.

2. **Closed-Loop 4-Stage TSPU Classifier -> 1-Click Fix (`fe-app-forkop/src/forkop/tabs/diagnostic/symptomGuide.ts`, `fe-app-forkop/src/forkop/next/workflows.ts`)**
   - Added 1-tap domain preset chips (`youtube.com`, `discord.com`, `cloudflare.com`) above the TSPU classifier input.
   - Numbered the 4 diagnostic pipeline stages (`1. DNS`, `2. TCP`, `3. TLS ClientHello`, `4. Передача 64 КБ / лимит 16–20 КБ`) with responsive 4 -> 2 (`<= 1100px`) -> 1 (`<= 640px`) column layout.
   - Added contextual 1-click remediation actions:
     - `[data-tspu-fix-route]`: calls `navigateToRule(panel, { kind: 'site', section, option: 'domain', site })`, opening the native rule modal and pre-filling the Quick Site preview input (`[aria-label="Сайт или адрес страницы"]`) with the blocked domain while keeping native LuCI validation and Save/Apply authoritative.
     - `[data-tspu-fix-dns]`: navigates directly to `Settings` -> `dns_type` when stage 1 detects DNS tampering.

3. **Frictionless Source & Subscription Management (`luci-app-forkop/htdocs/luci-static/resources/view/forkop/section.js`)**
   - **Pre-save Subscription Preview**: Added Unicode country flags (`previewCountryFlag`) and live search (`input[type="search"][data-sub-preview-search]`) when a previewed subscription contains `> 6` servers, updating the visible chip set and `Previewed servers (shown / total)` counter in real time.
   - **WireGuard / AmneziaWG / 1-Click WARP Helper**: Replaced the stacked single-column form with a responsive 2-column `.fkp-wg-warp-grid` (`1fr` on `<= 760px`), added direct `.conf` / `.txt` / `.ini` file upload (`input[type="file"][data-wg-conf-file]`), and live protocol auto-detection (`[data-wg-conf-detected]`) distinguishing `AmneziaWG` (`Jc`/`Jmin`/`Jmax`/`S1`/`S2`/`H1`–`H4`) from standard `WireGuard` as soon as the user pastes or selects a file.

4. **Plain-Language P2P Direct Traffic & Console Open NAT Visibility (`fe-app-forkop/src/forkop/workspace/formGuide.ts`, `fe-app-forkop/src/forkop/workspace/rules.ts`)**
   - Promoted `bittorrent_direct` and `torrserver_direct` out of buried settings into an open `Прямой трафик и торренты` group on `Settings`.
   - Added `· Консольный режим (UDP напрямую)` directly to `renderRuleRoute` summaries in the Rules table when `console_mode === '1'`.
