# Установка и обновление 1.1.4

## Подготовка

Сохраните резервную копию OpenWrt и экспорт профиля Forkop вне роутера, а также
пакеты предыдущей рабочей версии. Экспорт содержит пароли и ключи: храните его
как секрет. Обеспечьте локальный доступ к роутеру для восстановления связи.
Проверьте свободное место, зависимости и используемый менеджер пакетов.

Скачайте файлы из [релиза 1.1.4](https://github.com/m0llusca/forkop-next/releases/tag/1.1.4):

| Назначение | opkg | apk |
| --- | --- | --- |
| Backend | `forkop_1.1.4.ipk` | `forkop_1.1.4.apk` |
| Панель LuCI | `luci-app-forkop_1.1.4.ipk` | `luci-app-forkop_1.1.4.apk` |
| Русский перевод | `luci-i18n-forkop-ru_1.1.4.ipk` | `luci-i18n-forkop-ru_1.1.4.apk` |

Пакеты Forkop содержат переносимые скрипты и интерфейс. Сам sing-box — отдельный
компонент, его сборка должна соответствовать архитектуре и ABI роутера.
Не смешивайте IPK и APK. Сверьте скачанные файлы с `SHA256SUMS.txt` релиза:

```sh
sha256sum -c SHA256SUMS.txt --ignore-missing
```

Команду выполняйте на компьютере с GNU sha256sum в каталоге скачанных файлов.
Убедитесь, что проверен каждый устанавливаемый пакет. Контрольные суммы
проверяют целостность; независимой подписью релиза они не являются.

## Установка пакетов

Перенесите выбранные файлы на роутер в `/tmp`. Установите backend и LuCI через
менеджер пакетов OpenWrt. При opkg пример выглядит так:

```sh
opkg update
opkg install /tmp/forkop_1.1.4.ipk /tmp/luci-app-forkop_1.1.4.ipk
opkg install /tmp/luci-i18n-forkop-ru_1.1.4.ipk
```

Последняя строка нужна для русского перевода. Для apk используйте штатную
установку локальных APK в вашей OpenWrt; самодельные пакеты этого релиза
не подписаны ключом репозитория OpenWrt. Сначала проверьте их SHA256, затем
при необходимости явно разрешите локальные неподписанные пакеты:

```sh
apk update
apk add --allow-untrusted /tmp/forkop_1.1.4.apk /tmp/luci-app-forkop_1.1.4.apk
apk add --allow-untrusted /tmp/luci-i18n-forkop-ru_1.1.4.apk
```

Не удаляйте конфигурацию `/etc/config/forkop`. При конфликте конфигурационных
файлов сохраните действующие настройки и сравните предложенные изменения.
После установки обновите страницу LuCI. Интерактивный `install.sh` этого
репозитория также использует релизы `m0llusca/forkop-next`, но выбирает последний
релиз, а не фиксирует 1.1.4; для воспроизводимого обновления используйте файлы выше.

## REALITY и обновление ядра

Установка Forkop 1.1.4 сама по себе не заменяет старый sing-box. В управлении
компонентом выбирается вариант Extended, а обновление берёт последний стабильный
релиз: выбора точной версии в интерфейсе нет. Для проверенного здесь профиля
подтвердите, что предлагается **1.14.3-extended-2.7.3**, подходящий роутеру.
Если предлагается другая версия, установите именно этот официальный релиз
отдельно, проверив SHA256 и архитектуру, либо дождитесь его отдельной проверки.
Старый Extended 2.6.5 не понимает новый параметр. Обновление проверяет официальный
адрес и SHA256 до замены файлов. Более новый релиз не получает автоматически
допуск: для неизвестного исполняемого файла версия в названии не подтверждает поддержку.

Примените конфигурацию, выберите нужное подключение и выполните его явную
HTTPS-проверку совместимости в панели. Проверка списка обновлений 3x-ui/Xray
показывает официальные версии; удалённую панель она не обновляет.

Исправленный профиль автоматически использует гибридный обмен ключами только
при допущенном по SHA256 ядре, REALITY и Chrome uTLS, когда поле ещё не задано.
Явное `false` оставляет старое поведение; иной fingerprint не заменяется.
Не отключайте проверку сертификата для обхода ошибки REALITY.
Доказанные сочетания и ограничения перечислены в [COMPATIBILITY](COMPATIBILITY.md).

## Проверка и восстановление

Проверьте DNS, обычный доступ, выбранные маршруты, IPv4/IPv6, переключение
подключений и перезапуск службы по [контрольному списку](ACCEPTANCE.md).
Предварительный просмотр и откат профилей относятся к конфигурации.
Откат обновления ядра восстанавливает локальный исполняемый файл, библиотеку
и службу; он не восстанавливает точную регистрацию в базе пакетов.

Если обновление пакетов не подходит устройству, установите сохранённые пакеты
предыдущей версии через её менеджер пакетов и восстановите сохранённую
конфигурацию. Отдельно восстановите совместимое ядро при его замене.
Не считайте откат профиля откатом всех установленных пакетов.
