# Forkop Next 1.1.5

Выпуск подготовлен к публикации. Установочные пакеты 1.1.5 ещё не опубликованы.
Отдельное ARM64-ядро и исходники доступны в
[предварительном релизе ядра](https://github.com/m0llusca/forkop-next/releases/tag/core-1.14.3-extended-2.7.3-forkop-record1).

## Простой обзор соединения

- На главной странице видны состояние службы, выбранный сервер, управление
  включением и отключением, явная проверка доступа и доступные данные трафика.
- Состояние процесса, прежняя задержка и результат текущей проверки показаны
  отдельно. Ошибка или отсутствие данных не выдаются за успешное соединение.
- Профили и восстановление, временные правила, Smart Detect, совместимость и
  инструменты устройств загружаются при открытии. Все прежние вкладки сохранены.
- Обзор не ждёт определения возможностей всех компонентов. Пока идёт проверка,
  сохранение правил не перезаписывает ещё не загруженные настройки.
- Сохранены защита сравнения профиля перед применением, откат, темы LuCI и
  мобильная компоновка. Старая настройка YACD без секрета не блокирует сохранение
  несвязанных правил; новое удалённое включение по-прежнему требует секрета.

## Отдельное исправленное ядро Extended

`1.14.3-extended-2.7.3-forkop-record1` — настоящий UPX-сжатый ARM64-вариант,
сохраняющий все сборочные теги и возможности Extended. Исправление оформления
первого REALITY ClientHello сохраняет аутентификацию, проверку сертификата и
дальнейший трафик. [Патч, лицензия и сборка](../../core-patches/README.md)
опубликованы вместе с точными контрольными суммами.

Генератор добавляет `tls.reality.record_fragment_size: 256` только для точного
допущенного по SHA256 ядра, включённого REALITY и Chrome uTLS, когда поле
отсутствует. Явный `0` сохраняет прежнее поведение. Явные целые значения
`0..16384` требуют проверенной record-capability. Обычные ядра и другие
архитектуры автоматически не заменяются.

После установки backend 1.1.5 ядро выбирается отдельной командой:

```sh
forkop component_action sing_box install_forkop_record_compressed
```

Команда допускает подлинный проверенный сжатый Extended либо отсутствие ядра
без пакета-владельца. Проверяются источник, архитектура, версия, SHA256 и
возможности; обновления сохраняют собственный канал. Неизвестный источник или
недостаток подтверждения не вызывают молчаливую замену на другое ядро. Ошибка
восстанавливает прежние локальные файлы, вариант, версию и канал; точное состояние
базы пакетов не реконструируется.

## Проверено и что ещё предстоит

| Проверка | Результат и область |
| --- | --- |
| Новый интерфейс | 639 frontend-тестов, форматирование, линтер, проверка типов и сборка; native-фикстуры загрузки и сохранения |
| Backend и ядро | Изолированные проверки настоящим ucode: генерация, валидация, допуск SHA256, канал обновлений и откат |
| ARM64 UPX-ядро → Xray 26.10.21 | Две серии по 8/8; неверный REALITY-ключ отклонён |
| ARM64, несжатый вариант → Xray 26.7.28 | 8/8 в отдельной серии |
| Действующее ARM64-подключение с новым backend и ядром | 8/8 ответов авторизованного контроллера с HTTP 200 и числовой задержкой; DNS, HTTPS, закреплённый канал обновления и работа службы проверены. Рабочий выбор маршрута сохранён |
| Живая 3x-ui 3.10.2 | Обновлена и проверена; это не проверка всех возможностей панели |
| Официальный Extended 2.7.3 на Linux amd64 | Сохранены REALITY/Vision-проверки с Xray 26.6.27 / 26.9.30 / 26.10.21 и отказы при неверных реквизитах |

На одном ARM64-устройстве чтение `next status` сократилось с **3,57 с** до
**0,06–0,08 с**. Это время backend-команды, не первого отображения страницы.

Новый интерфейс ещё не развёрнут на устройстве. Браузерная визуальная проверка,
снимки телефона/десктопа и измерение первого полезного отображения не выполнены.
Короткие живые серии не гарантируют долговременную устойчивость или совместимость
всех архитектур, маршрутов и будущих Xray. XHTTP и VLESS Encryption сохраняют
проверки генерации, схемы и запуска без подтверждённой передачи трафика.
Автоматический резервный клиент Xray не реализован.

## Перед обновлением

Дождитесь опубликованных пакетов 1.1.5 и их `SHA256SUMS.txt`, сохраните резервную
копию и прежние рабочие пакеты. Установка приложения не заменяет ядро сама по себе.
После обновления проверьте выбранное подключение, DNS, HTTPS и IPv4/IPv6 на своём
устройстве. Экспорт профиля содержит секреты конфигурации.
