# Forkop Next 1.2.1-r2

Исправлена маршрутизация HTTPS по доменным правилам. Защита локальных адресов
и разделение DNS сохраняются; пакет устанавливает необходимую зависимость
`kmod-nft-fib`.

Перезапуск службы и обновление пакетов сохраняют DNS и выбранные выходы на время
технической остановки. Обычная команда остановки по-прежнему возвращает DNS
в исходное состояние; при неудачном запуске применяется безопасное восстановление.

Редактор правил LuCI сохраняет домены при повторном открытии и сохранении.
Обновление не восстанавливает записи, удалённые до установки исправления.

Исправление выпускается под отдельной версией `1.2.1-r2`. Имена APK/IPK,
метаданные пакетов и отображаемая версия используют полное обозначение ревизии.
Обновление поддерживает прежние версии вида `x.y.z` и версии вида `x.y.z-rN`,
где `N` — положительное число без ведущих нулей.

Перед обновлением сохраните резервную копию настроек.
