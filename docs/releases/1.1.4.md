# Forkop Next 1.1.4

Первый публичный выпуск этого форка объединяет новую панель и безопасное
применение настроек с исправлением REALITY для свежих Xray. Основное ядро —
официальный sing-box Extended **1.14.3-extended-2.7.3**.

## Возможности

- Простой и подробный обзор, светлая/тёмная тема, мобильная компоновка,
  восстановление соединения панели и понятные ошибки чтения состояния.
- Профили: импорт/экспорт, предварительный просмотр, проверка изменений,
  защита от применения устаревшего просмотра, журнал, восстановление и откат.
- Выбор подключения для IPv4-устройства, временные правила с истечением срока,
  игровые наборы доменов магазинов и загрузок.
- Объяснение маршрута и отдельная проверка фактической доступности,
  сохранение ручного выбора, до четырёх параллельных измерений задержки.
- Включаемый Smart Detect предлагает проверенную альтернативу после повторных
  ошибок; применение требует явного принятия предложения.
- Проверка официальных обновлений 3x-ui/Xray и совместимости выбранного
  подключения; адаптация DNS и загрузки rule-set к sing-box 1.13/1.14.

## Исправления

- REALITY: интегрирован upstream-параметр `support_x25519mlkem768` Extended.
  Автоматическое включение ограничено SHA256 проверенного исполняемого файла,
  REALITY и Chrome uTLS. Явные настройки пользователя сохранены.
- Обновление ядра проверяет официальный URL и SHA256 до распаковки/запуска.
  Исправлены ранние ошибки резервирования, сохранение старой библиотеки,
  восстановление службы и определение Extended без маркера варианта.
- TProxy: fwmark и таблица должны относиться к одному полному общему правилу;
  ограниченные правила и похожие IPv6-маршруты не подтверждают готовность.
- Trojan по умолчанию использует TLS. Неизвестный режим безопасности вызывает
  отказ, известные варианты регистра нормализуются, ссылки без security
  сохраняют намерение TLS/REALITY из SNI/peer, ALPN, fingerprint и public key.
  Явный `security=none` остаётся осознанным выбором.

## Проверки

Перед выпуском пройдены **243 backend-теста без пропусков, 70 shell-наборов,
594 frontend-теста**, форматирование, линтер, сборка интерфейса,
дифференциальный ShellCheck и сборка шести пакетов IPK/APK.
Выпуск повторно проходит backend/frontend gates и сборку пакетов.

| Проверка | Результат и область |
| --- | --- |
| REALITY/Vision, Extended 2.7.3 → Xray 26.6.27 / 26.9.30 / 26.10.21 | Реальная передача случайного HTTPS-содержимого в Linux amd64, неверные UUID/ключ/short ID отклоняются |
| TLS/Vision, stock sing-box 1.13.7 / 1.14.3 → Xray 26.10.21 | Передача HTTPS и строгая проверка сертификата |
| 3x-ui 3.10.2 | Исходники и сериализация API; без развёртывания живой панели |
| Extended XHTTP / VLESS Encryption | Генерация конфигурации, проверка схемы и запуск; без live interop |
| TProxy и восстановление | Реальный CLI с изолированными внешними командами; без проверки ядра роутера |

Тесты не гарантируют работу всех будущих Xray, архитектур или серверных профилей.
Стендовая проверка ядра и проверка preflight выполняются отдельно.
На настоящем роутере и Aeza этот выпуск в рамках подготовки не устанавливался.

## Обновление

Скачайте три IPK либо три APK и `SHA256SUMS.txt` из Assets релиза, проверьте
целостность и сохраните резервную копию. Перевод — необязательный пакет.
**Обновите компонент sing-box отдельно:** Extended 2.6.5 не содержит исправления.
После применения выполните HTTPS-проверку выбранного подключения.

Xray остаётся резервным направлением; второй runtime и автоматическое
переключение на него не входят в 1.1.4. Откат ядра не реконструирует базу пакетов.
Экспорт профиля содержит секреты. IPv4-контроль устройств не отключает
существующую IPv6-маршрутизацию; игровые наборы не охватывают все игровые сессии.
