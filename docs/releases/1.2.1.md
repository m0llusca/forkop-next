# Forkop Next 1.2.1

Исправлено сохранение доменов в редакторе правил LuCI. Блок быстрого добавления
сайта теперь находится вне корневого элемента нативного текстового поля.
Сохранение без изменений больше не читает пустое значение вместо доменов;
добавление сайта, сохранение и повторное открытие сохраняют прежние записи.

Формат конфигурации, существующие правила, источники и возможности Extended
сохранены. Установка приложения сама по себе ядро не заменяет.

Перед обновлением сохраните резервную копию настроек. Если домены были удалены
предыдущим сохранением, обновление не восстанавливает их автоматически: нужен
проверенный файл резервной копии. Перед применением убедитесь, что список полон.

Разработка: две новые проверки сначала воспроизвели ошибку и прошли после
исправления; все 915 frontend-тестов, типы, lint и frontend-сборка прошли.
Публикация пакетов требует успешного полного release gate и сборки этого дерева.
Подробности — в [TDD-записи](../tdd/native-domain-widget-preservation.md).
